# 이름결 結

성씨와 생년월일시를 넣으면 **사주팔자·오행·용신**을 분석하고, 대화하듯 조건을 말하면
이름 후보를 추려 주는 작명 웹앱입니다. `index.html`을 더블클릭하면 서버 없이 바로 열리고,
입력한 정보는 **이 기기의 브라우저에만 저장**됩니다.

**바로 열기:** https://singnii526.github.io/ireum-gyeol/ (GitHub Pages, `main` 브랜치에 push하면 1분 안에 반영)

## 흐름

| 단계 | 하는 일 |
|---|---|
| **1 기본 정보** | 성씨(한자 선택), 성별, 양력 생년월일, 태어난 시각, 출생 지역(지방시 보정) → 사주 네 기둥, 오행 분포, 일간, 신강·신약, 용신·희신·기신 |
| **2 작명 방향** | 이름 8개에 좋아요/별로예요 → 글자 취향 학습. 담고 싶은 뜻, 돌림자, 피할 글자, 받침 조건, 형제 이름 |
| **3 이름 추천** | 점수순 추천 카드 + 대화창. 말로 조건을 바꾸면 바로 다시 골라 줌 |
| **4 보관함·비교** | 담은 이름을 표로 비교, 최종 선택, 이름 증서 저장, 가족 공유 링크 |
| **★ 후기** | 후기 작성(이 기기에 저장) + 예시 후기 |

## 점수 (100점)

아래 네 항목 합계(90점)를 100점 만점으로 환산합니다. 같은 사주·같은 이름이면 언제나 같은 점수입니다.
취향 테스트와 고른 느낌은 **점수에 넣지 않고 추천 순서에만** 반영합니다.

| 항목 | 배점 | 기준 |
|---|---|---|
| 수리 4격 | 40 | 원·형·이·정격이 81수리 길수면 각 10점 |
| 발음오행 | 20 | 성→이름1, 이름1→이름2가 상생 10 / 같은 기운 6 / 상극 0 |
| 음양 | 10 | 세 글자 획수의 홀짝이 섞여 있으면 10 |
| 자원오행 | 20 | 글자마다 용신 10 / 희신 7 / 사주에 없는 기운 6 / 기신 0 / 그 외 4 |

## 대화창이 알아듣는 말

- 느낌: “밝고 씩씩한”, “지혜로운”, “예쁜”, “자연스러운” … (뜻 태그 8종)
- 글자: “‘준’ 자 들어간”, “‘민’ 자는 빼줘”, “서로 시작”, “돌림자 현”
- 조건: “받침 없는”, “부드러운”, “물 기운 있는”, “용신 넣어서”, “쉬운 한자로”, “4격 모두 좋은 것만”, “중성적인”
- 기타: “하윤 어때?”(특정 이름 분석), “더 보여줘”, “처음부터”

외부 AI 없이 규칙으로 해석합니다. 실제 LLM 대화가 필요하면 서버를 두고 Claude API를 붙이면 됩니다.

## 원본 사이트에 없는 기능

- **부모가 정한 이름으로 한자 찾기**: 추천 목록 아래 "혹시 마음에 오는 이름이 없나요?"에 한글 이름을 적으면 그 소리로 만들 수 있는 한자 조합을 점수순으로 보여 줍니다. 한자 사전에 없는 글자이거나 70점 이상 조합이 없으면, 소리가 비슷한(초성·중성·받침 비교) 실제 쓰이는 이름 중 점수 좋은 이름을 추천합니다. 순우리말 이름은 한글 이름으로 출생신고할 수 있다는 안내도 함께 보여 줍니다.

- **출생신고 통계**: 이름별 출생신고 수(남/여), 한 해 평균, 순위. 대법원 전자가족관계등록시스템 '선호하는 출생자 이름 현황' 2008~2019년 합산 자료(정리본 github.com/randkid/name)에서 이름결이 추천할 수 있는 2,562개 이름만 골라 넣었습니다. 2020년 이후 수치는 없습니다.
- **부모님 사주 · 가족 궁합**: 아빠·엄마 생년월일시(선택)를 넣으면 각자의 사주와 아이와의 궁합(일간 생극, 천간합, 일지 합·충, 띠 삼합·육합·충, 부족 오행 보완)을 점수와 문장으로 보여 줍니다.
- **가족 시너지 이름**: 부모와 아이 사이를 잇는 통관 오행, 가족 모두에게 부족한 오행을 담은 이름에 '가족 시너지' 표시를 붙이고 추천 순서를 올립니다. 이름 점수에는 넣지 않습니다. 대화창에 "가족 시너지 좋은 이름"이라고 하면 70점 이상만 남깁니다.

- **이름 듣기**: 브라우저 음성 합성으로 “김민준. 민준아!”를 읽어 줌
- **실제 소리·부를 때 발음**: 연음·비음화·유음화·격음화를 반영해 [기므누]처럼 표시
- **놀림 단어 체크**: 발음했을 때 놀림받을 만한 단어와 겹치는지 확인 (조건으로 기본 제외)
- **영문 표기**: 국어의 로마자 표기법 + 관용 성씨 표기(Kim, Lee…), 영어권에서 헷갈리는 철자(eo, eu…)·어색한 단어 경고
- **형제·자매 어울림**: 돌림자 여부, 초성이 너무 같은지, 받침 리듬, 첫소리 오행 비교
- **흔한 정도**: 인기 이름 목록에서의 위치로 추정
- **이름 증서 PNG 저장** (1080×1350)
- **가족 공유 링크**: 후보 목록(선택 시 생년월일 포함)을 URL에 담아 공유, 받은 쪽에서 같은 비교표로 확인

## 한자 데이터 (인명용 한자)

모든 추천·검색 한자는 **대법원 인명용 한자표(2024.6 시행, 9,389자)** 에 있는 글자만 씁니다. 상세 화면에 글자마다 "대법원 인명용 한자 ✓"가 표시됩니다.

| 묶음 | 쓰임 | 기준 |
|---|---|---|
| 작명 검수 한자 (약 140자) | 자동 추천의 중심 | 옥편 기준 원획·자원오행을 손으로 확인 |
| 교육용 기초한자 중 좋은 뜻 (31자) | 자동 추천에 추가 | 아래 확장 기준 + 교육용 1,800자 |
| 확장 인명용 한자 (약 2,800자) | 부모가 직접 적은 이름, 대화창 "OO 어때?" | 아래 확장 기준 |

확장 기준: 인명용 · 훈 있음 · 부정적 뜻 아님 · **원획을 두 방법(번체 필획+부수 본래 획수 / 강희자전 배열에서 추정한 나머지 획수)으로 계산해 일치** · 부수로 자원오행이 분명함(木艸竹禾糸 / 火日 / 土山田 / 金玉石 / 水雨冫). 心·人·言·女처럼 작명 책마다 오행이 갈리는 부수의 글자는 넣지 않았습니다. 같은 이름 안에서 한자를 고를 때는 검수 한자 > 교육용 > 그 밖 순으로 가중치를 둬서, 드문 글자가 획수만으로 앞서지 않게 했습니다(표시 점수는 그대로).

- `hanja-db.js`는 `tools/build-hanja.js`로 만듭니다. 입력: 대법원 목록·훈음(github.com/rutopio/Korean-Name-Hanja-Charset, MIT), Unicode Unihan(kRSUnicode, kTotalStrokes, kKangXi, kKoreanName, kKoreanEducationHanja).
- 대법원 목록은 姬를 姫(U+59EB)로 등록하고 있어, 姬(U+59EC)는 추천에서 뺐습니다.

## 한계와 바꿔야 할 것

- 지방시 보정: (출생지 경도 − 135°) × 4분. 서울 −32분, 부산 −24분. 1954.3.21~1961.8.9 등 표준 자오선이 127.5°였던 시기와 1987·1988년 서머타임(−60분)을 반영합니다. 그 이전 서머타임 시기는 반영하지 않습니다.
- 절기는 해마다 같은 날짜로 근사합니다. 절입일 당일·전날 출생이면 월주가 하루 차이로 달라질 수 있습니다.
- 음력 입력과 두 글자 성(남궁·제갈 등)은 아직 지원하지 않습니다.
- 용신은 억부법을 단순화해 계산합니다. 참고용입니다.
- **후기란의 ‘예시’ 후기 7개는 화면 구성용 샘플입니다.** 실제 사용자 후기인 것처럼 게시하면 표시광고법상
  기만 광고가 될 수 있으니, 공개 전에 실제 후기로 바꾸거나 지워 주세요.
  후기를 사용자끼리 공유하려면 Supabase 같은 DB가 필요합니다.
- 유료 결제·회원 기능은 없습니다.
